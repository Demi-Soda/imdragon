# 임용 랜덤 학습

임용고시 공부 자료(PDF·이미지·텍스트·HWP·HWPX)를 원본 그대로, 무작위 순서로 하나씩 보여주는 학습 앱입니다.
한 바퀴를 다 볼 때까지 같은 자료는 다시 나오지 않고, 필기·형광펜·메모를 자료 위에 따로 저장합니다.

**앱 주소: <https://demi-soda.github.io/imdragon/>**

이 앱은 앱 스토어가 아니라 인터넷 주소로 설치합니다. 브라우저에서 주소를 연 뒤 '홈 화면에 추가'를 한 번 누르면, 바탕화면에 아이콘이 생기고 일반 앱처럼 쓸 수 있습니다.

> 가져온 공부 자료와 필기는 각자의 핸드폰 안에만 저장됩니다. 이 저장소나 서버, 다른 사람에게 보내지지 않습니다.

## 왜 홈 화면에 추가해야 하나요

- **앱처럼 열립니다.** 주소창 없는 전체 화면으로 열려서 화면을 더 넓게 씁니다.
- **인터넷이 없어도 열립니다.** 처음 한 번 연 뒤에는 프로그램 파일이 핸드폰에 저장됩니다.
- **자료가 더 안전하게 남습니다.** 특히 아이폰은 브라우저에서만 쓰면 오래 안 쓴 사이트의 저장 데이터를 지울 수 있습니다. 홈 화면에 추가하면 이 문제를 피할 수 있다고 알려져 있습니다.

## 시작하기 전에

1. **카카오톡으로 받은 링크는 핸드폰 기본 브라우저로 다시 여세요.**
   카카오톡·밴드 같은 앱 안에서 링크를 누르면 그 앱 안의 브라우저로 열리는데, 여기서는 홈 화면 추가가 안 됩니다.
   화면 오른쪽 위나 아래의 메뉴(⋮ 또는 …)에서 **[다른 브라우저로 열기]**를 누르고, 안드로이드는 크롬이나 삼성 인터넷, 아이폰은 사파리를 고르세요.
2. **처음 한 번은 인터넷이 연결된 상태여야 합니다.**
   주소를 열고 화면이 다 나오면 프로그램이 핸드폰에 저장됩니다. 그다음부터는 인터넷 없이도 열립니다.

시크릿 모드(비공개 브라우징)에서는 저장한 자료가 나중에 지워질 수 있으니 일반 창에서 여세요.

## 안드로이드 — 크롬

1. 크롬에서 [앱 주소](https://demi-soda.github.io/imdragon/)를 엽니다. 화면이 다 나올 때까지 기다립니다.
2. 오른쪽 위 점 세 개(⋮) 메뉴를 누릅니다.
3. **[앱 설치]** 또는 **[홈 화면에 추가]**를 누릅니다.
   - [홈 화면에 추가]를 누른 뒤 [설치]와 [바로가기 만들기] 중 고르는 창이 뜨면 **[설치]**를 고르세요. 바로가기는 주소창이 달린 브라우저로 열립니다.
   - 화면 아래에 '앱 설치' 안내가 뜨면 그것을 눌러도 됩니다.
4. 확인 창에서 **[설치]**(또는 [추가])를 누릅니다.
5. 홈 화면이나 앱 목록에 **임용학습** 아이콘이 생깁니다. 이제부터는 이 아이콘으로 여세요.

크롬 버전에 따라 메뉴 이름이 조금 다를 수 있습니다. '설치'나 '홈 화면'이 들어간 메뉴를 찾으면 됩니다.

## 안드로이드 — 삼성 인터넷

1. 삼성 인터넷에서 [앱 주소](https://demi-soda.github.io/imdragon/)를 엽니다.
2. 주소창에 설치 아이콘(아래 화살표 또는 +)이 보이면 눌러서 설치합니다. 없으면 다음 단계로 갑니다.
3. 오른쪽 아래 가로줄 세 개(≡) 메뉴를 누릅니다.
4. **[현재 페이지 추가]**(또는 [페이지 추가]) → **[홈 화면]**을 누릅니다.
5. 이름을 확인하고 **[추가]**를 누릅니다.

삼성 인터넷의 한국어 메뉴 이름은 버전마다 조금씩 다릅니다. '추가'와 '홈 화면'이 들어간 메뉴를 찾으세요. 잘 안 되면 크롬으로 열어 위 방법을 쓰세요.

## 아이폰·아이패드 — 사파리

1. 사파리에서 [앱 주소](https://demi-soda.github.io/imdragon/)를 엽니다.
2. **공유 버튼**(네모에서 위로 화살표가 나온 모양)을 누릅니다.
   - iOS 26부터는 주소창 오른쪽 점 세 개(⋯)를 누른 뒤 **[공유]**를 누릅니다.
   - 그보다 이전 버전은 화면 아래쪽(아이패드는 위쪽)에 공유 버튼이 바로 있습니다.
3. 목록을 아래로 내려 **[홈 화면에 추가]**를 누릅니다.
4. **[웹 앱으로 열기]** 스위치가 보이면 켜 둔 채로 둡니다. 끄면 앱이 아니라 사파리 즐겨찾기처럼 열립니다.
5. 오른쪽 위 **[추가]**를 누릅니다.

> **아이폰 주의:** 홈 화면 아이콘으로 연 앱과 사파리로 연 화면은 **저장 공간을 따로 씁니다.**
> 사파리에서 넣은 자료는 홈 화면 앱에 안 보일 수 있으니, 아이콘을 만든 뒤 **아이콘으로 열어서** 자료를 가져오세요.
> (일반적으로 알려진 동작이며 실제 기기에서 확인하지 못했습니다.)

### 아이폰에서 크롬을 쓸 때

iOS 16.4 이상이면 크롬에서도 홈 화면에 추가할 수 있습니다. 주소창의 공유 버튼을 누른 뒤 [홈 화면에 추가]를 찾으세요. 메뉴 위치가 헷갈리면 사파리를 쓰는 편이 확실합니다.

## 잘 저장됐는지 확인하기

- [ ] 홈 화면(또는 앱 목록)에 남색 바탕에 '임' 글자가 있는 **임용학습** 아이콘이 있다.
- [ ] 아이콘을 누르면 주소창 없이 전체 화면으로 열린다.
- [ ] 비행기 모드를 켜고 열어도 앱이 열리고, 넣어 둔 자료가 보인다.

세 가지가 모두 되면 제대로 저장된 것입니다. 주소창이 보이면 바로가기로 만들어진 것이니, 아이콘을 지우고 다시 추가하면서 [설치]나 [웹 앱으로 열기]를 고르세요.

### 새 버전 받기

따로 할 일은 없습니다. 인터넷이 연결된 상태로 앱을 열면 새 버전을 받아 두고, '새 버전을 받았습니다' 안내가 뜹니다. 앱을 완전히 닫았다가 다시 열면 적용됩니다. 가져온 자료와 필기는 그대로 남습니다.

## 자주 생기는 문제

| 이럴 때 | 이렇게 하세요 |
| --- | --- |
| 메뉴에 '홈 화면에 추가'가 없어요 | 카카오톡 등 앱 안 브라우저일 가능성이 큽니다. [다른 브라우저로 열기]로 크롬·삼성 인터넷·사파리에서 여세요. |
| 아이콘을 눌렀더니 주소창이 보여요 | 바로가기로 저장된 것입니다. 아이콘을 지우고 [설치] 또는 [웹 앱으로 열기]를 켜서 다시 추가하세요. |
| 아이폰에서 넣은 자료가 안 보여요 | 사파리와 홈 화면 앱은 저장 공간이 따로입니다. 자료를 넣은 쪽으로 열거나, 홈 화면 앱에서 다시 가져오세요. |
| 인터넷 없이 열면 연결 오류가 나요 | 인터넷이 되는 곳에서 한 번 열어 화면이 다 나오길 기다린 뒤 다시 해 보세요. |
| 아이콘을 실수로 지웠어요 | 주소로 다시 들어가 추가하면 됩니다. 안드로이드는 보통 자료가 남아 있지만, 아이폰은 앱을 지우면 자료도 함께 지워질 수 있습니다. |

### 자료가 지워지는 경우

가져온 자료와 필기는 핸드폰 안에만 있어서 아래 경우에는 함께 사라집니다.

- 브라우저의 방문 기록·사이트 데이터 삭제
- 핸드폰 교체 또는 초기화
- (아이폰) 홈 화면 앱 삭제

미리 **[메뉴] → [기록 내보내기]**로 필기·메모·순서를 파일로 백업해 두세요. 공부 자료는 원본 zip을 다시 가져오면 되고, 백업한 기록을 [기록 가져오기]로 넣으면 필기까지 돌아옵니다.
